# Social Media Engagement Analysis

## Project Overview
This project analyzes social media engagement across platforms like Facebook, Instagram, Twitter, and Reddit. It helps to understand which platform, campaign and sentiment gives highest engagement.

## Tools Used
- Power BI for Dashboard
- Python for Data Cleaning
- SQL for Analysis
- Excel for Dataset

## Dashboard Features
- Total Posts: 12k
- Total Likes: 30M
- Total Comments: 6M
- Total Engagement: 48M
- Platform-wise, Campaign-wise and Sentiment-wise Analysis

## Files in this Repository
- social_media_analysis.pbix - Power BI Dashboard File
- Dataset - Raw Data
- Clean Data - Cleaned Data
- SQL - SQL Queries
- Social.py - Python Cleaning Code
- Social_media_engagement.docx - Project Report

## Key Insights
- Instagram has highest engagement
- Positive sentiment posts get more likes
- Brand Awareness campaign performed best
